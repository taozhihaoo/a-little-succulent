## 0. 两种风格方向并存

| | 写实向（当前默认） | 绚丽向（本参考） |
| --- | --- | --- |
| 定位 | 桌面上真实的小生命 | 卡通饱满、糖果绚丽 |
| 叶形 | 自然解剖比例 | 短肥圆、卡通团块 |
| 色彩 | 自然绿 + 应激粉晕（克制） | 高饱和基-尖强渐变、品种色板 |
| 光 | 实时昼夜三段色温 + 影子 | 手绘感固有色 + 柔和 AO |
| 受众 | 治愈/真实感 | Wholesome/Cute 系 |

两方向作为**基因预设并存**（同一引擎、同一套基因系统，不同默认值与色板），不互相替代。

## 1. 形体语言拆解（绚丽的来源）

### 1.1 单叶：短、肥、圆

* 长宽比接近 **1 : 0.8**（我们当前 1 : 0.55）
* 叶尖**全圆钝**，无收尖——"肥厚的勺子"
* 厚度感强：横截面接近半圆，不是扁片
* 中脉不可见，叶背圆弧过渡

### 1.2 排列：极密 + 强重叠

* 可见 3~4 环 + 中心心叶，每片叶约 **1/3 被邻叶遮挡**
* 叶间隙几乎为零——紧密是"饱满"观感的第一来源

### 1.3 莲座轮廓：馒头形

* 叶倾角从中心 ~30° 到外圈 ~65°，整体**向上收拢成碗**
* 不是"摊开的平盘"——外圈叶也不趴

### 1.4 群生

* 多中心高低错落（2~3 头），比单头生动
* 对应我们的子株系统（M4/M5），风格上要求子株与母株**紧贴群生**

### 1.5 花剑

* 细长杆 + 顶端小花串，作为**常态装饰**存在（游戏化处理）
* 对应我们的 M4 开花事件——绚丽向下花剑可以更早更频繁地作为观赏出现

## 2. 色彩语言拆解

### 2.1 单叶基-尖渐变（绚丽观感的第一来源）

* 基部绿/深色 → 中段过渡 → 叶尖强色（粉/红/橙/白）
* **渐变从叶片约 1/2 处开始加剧**，不是均匀过渡
* 我们已有 aT（基→尖）渐变管线，只需加强度量与提前起点

### 2.2 品种色板化

每品种 = 一组"基色 + 尖色"：

| 色系 | 基色 | 尖色 |
| --- | --- | --- |
| 粉 | 绿 | 粉白 |
| 橙红 | 深绿 | 橙红 |
| 白粉 | 灰绿 | 白粉 |
| 红白边 | 绿 + 红缘 | 红白 |
| 明黄 | 黄绿 | 明黄 |

### 2.3 明度策略

高饱和 + **高明度**（糖果系），不是深色系；中心新叶色浅、外圈老叶色深的辐射分布。

### 2.4 质感

哑光 smooth shading + 叶间深色缝隙阴影（类描边）；无镜面高光、无透光表现——纯靠固有色渐变。

## 4. 几何层改动点（leaf.ts）

1. **横截面更圆**：超椭圆指数上调，凸度感增强
2. **宽度轮廓**：前 40% 保持全宽、后段快速圆收（替代当前 sin 缓变）
3. **厚度基准上调**：配合 leafThickness 0.90

以上均为 leaf.ts 纯函数参数，不影响引擎与存档（generatorVersion 不变，形状参数走快照 shape 字段）。

## §5 游戏内实拍对照修正（2026-10-02，来源不具名）

拿到游戏内实拍（标题界面，白天顶视角，约 12 株）后，对 §3 参数映射的验证与修正：

**确认项**：短肥圆叶 ✅（实拍更极端，接近 1:0.9、尖部全半球）；密聚碗形 4~6 环 ✅；品种级整簇变色 ✅（非逐叶渐变，是底色级）；哑光手绘 ✅（全程无高光/透明感）。

**修正项**（已落地）：
1. **渐变带更宽**：色带覆盖叶面 40~60%、外环整叶淹没——shader stressMask pow 2.2→1.6、缘/肋权重 (0.25+0.75vC)→(0.35+0.65vC)、上限 0.6→0.7。
2. **更肥更钝**：绚丽 preset leafWidth 0.72→0.8、tipSharpness 0.25→0.12、leafLength 0.40→0.36。
3. **内浅外深双层色阶**（新发现）：内圈奶黄、外圈深粉的株内落差很明显——phenotype 三档色 young/mature 偏移幅度改为随 edgeContrast 增幅（0.3+0.35·edgeContrast），绚丽 0.9 → 落差 0.615、写实 0.55 → 0.49。
4. **低粉霜高红边**：绚丽 farina 0.15→0.08、edgeContrast 0.7→0.9（永久红边晕 blush=0.27）。

**未落地（备忘）**：花盆糖果色多样（橙/奶油/粉/薄荷）——当前单一赤陶，属后续品种/盆器特性，非本轮参数活。
