## 1. 范围与定位

* **原型 A：莲座型（Echeveria 类 / 拟石莲属气质）**，总方案 §9.1
* 目标不是"能生成多少种"，而是回答总方案 §76 的三个问题：
  1. 第一眼足够漂亮吗？
  2. 几天后能察觉"它变了吗"？
  3. 酝酿中的变化会勾人回来吗？
* **MVP 截止线（总方案 §77）**：新叶 / 缺水-恢复 / 轻微变色 / 徒长 / 昼夜 / 离线生长 / 微事件 / 履历 / 存档
* **MVP 不做**：开花、子株、叶插、老桩、晒伤、换盆、群生（M4 / M5 同原型扩展，见 §12）

分类声明（R9）：

| 缺水褶皱-恢复 | Realistic（简化：植株级水分） |
| 应激变色 | Simplified（真实存在，因果简化为三累积器） |
| 徒长 | Simplified |
| 季节节律 | Simplified |

## 2. 视觉定位

关键词：**饱满、粉霜、莲座、中心对称、温润**。

* 参考：成熟 Echeveria 的紧密莲座；外圈叶微展开、内圈叶直立聚拢
* 禁止：完美机械对称、塑料高光、均匀纯色、锯齿轮廓
* 每株必须有可察觉的个体差异（§3 约束 + §11 唯一性验收）

## 3. 基因参数表

全部 0～1 归一化，实际生效受范围约束（总方案 §10）。数值均为调参起点。

### 3.1 叶序

| 参数 | 范围 | 默认 | 映射 |
| --- | --- | --- | --- |
| leafDensity | 0.35～0.8 | 0.55 | 莲座总叶数 24～72 |
| rosetteCompact | 0.3～0.9 | 0.6 | 内圈直立角、环间距 |
| outerOpen | 0.2～0.8 | 0.45 | 外圈展开角 45°～80° |
| phylloJitter | 0～0.15 | 0.05 | 角度抖动（打破机械感） |

叶序基础：Vogel 螺旋（总方案 §11.2 允许的莲座基础），发散角 137.5°±基因微扰；环归属由半径阈值切分。

### 3.2 叶形

| 参数 | 范围 | 默认 | 映射 |
| --- | --- | --- | --- |
| leafLength | 0.3～0.7 | 0.5 | 外圈叶长 14～30 mm（场景尺度） |
| leafWidth | 0.4～0.8 | 0.6 | 宽 / 长比 |
| leafThickness | 0.45～0.85 | 0.65 | 厚 / 宽比（多肉感核心） |
| curvature | 0.2～0.7 | 0.45 | 纵向弯月程度 |
| tipSharpness | 0.2～0.8 | 0.5 | 叶尖聚拢感 |
| openness | 0.3～0.7 | 0.5 | 横截面开合角（浅匙 → 深凹） |

### 3.3 颜色与质感

| 参数 | 范围 | 说明 |
| --- | --- | --- |
| baseHue | 绿～蓝绿 | 基色板索引（原型色板内插值，总方案 §41.2） |
| stressHue | 粉 / 红 / 橙 / 紫 | 应激色板索引 |
| farina | 0～1 | 粉霜量（sheen 强度 + 表面提亮去饱和） |
| edgeContrast | 0～1 | 叶缘深色 / 红边基因倾向 |
| gloss | 0.3～0.7 | 基础光泽（与 farina 负耦合） |

### 3.4 习性

| 参数 | 范围 | 说明 |
| --- | --- | --- |
| growthRate | 0.3～0.8 | 出叶间隔系数 |
| waterTolerance | 0.3～0.8 | 缺水演化速度与耐受阈值 |
| stressColorPropensity | 0.2～0.9 | 变色容易度（个体"性格"核心，总方案 §26） |
| stretchPropensity | 0.2～0.8 | 徒长容易度 |
| droughtDecay | 0.4～0.9 | 应激累积衰减速度 |

### 3.5 基因耦合（总方案 §41.3，硬约束）

```text
leafDensity ↑    → leafLength ↓（×(1 − 0.35·density)）
leafThickness ↑  → leafWidth ↑（×(1 + 0.15·thickness)）
farina ↑         → gloss ↓
rosetteCompact ↑ → outerOpen ↓
stretch（环境）↑ → 叶宽 ↓、farina 视觉量 ↓
```

## 4. 几何生成

### 4.1 叶片（BufferGeometry 参数化，总方案 §11.1）

* 横截面：超椭圆扁匙形（宽度方向 exponent ≈ 2.4）；纵向：中肋弯月弯曲 + 叶尖收聚
* 网格：12（长）× 8（横）可调；目标单叶 ≤ 400 三角
* 顶点属性：`aT`（叶基→尖 0~1）、`aC`（中肋→缘 0~1）、`aRing`、`aAge`、`aRand`
  ——供 shader 做：turgor 褶皱（沿 aC 噪声位移）、应激色渐变（沿 aT）、风摆弯曲（沿 aT 加权）
* **整株单 Mesh**：全部叶合并；生长变化时重建（重建频率低，模拟小时级才可能发生一次）

### 4.2 莲座排布

```text
leaf i：θ = i × 137.508° × (1 + phylloJitter 抖动)
半径 r、倾角 tilt、叶长 s 由环曲线给出：
  内圈：tilt 10°～25°，叶短、直立
  中圈：tilt 35°～55°
  外圈：tilt 55°～80°，叶最长、展开
age / 缺水附加 droop：tilt += 5°～15°
```

### 4.3 茎与盆

* MVP：短茎桩 + 土丘（圆锥残缺面），老桩留给 M5
* 花盆：2 个旋转轮廓（素陶红陶 / 哑光水泥灰），截面 lathe；土面微凸圆盘
* 允许后续用少量外部资产替换盆（总方案 §39：程序化是手段不是卖点）

## 5. 生长规则

所有速率集中在一个 `GrowthTuning` 配置里（模拟日单位，调参只动这里）：

| 项 | 基准（模拟日） | 说明 |
| --- | --- | --- |
| 出叶间隔（生长季） | 3～7 天 / 片 | × growthRate × 季节系数 |
| 叶展开 | 出生 → 成熟 10～16 天 | maturity 0→1 |
| 叶维持 | 30～60 天 | 成熟平台期 |
| 叶衰老 | 15～30 天 | 转黄软化 → 外圈 droop |
| 脱落 | 衰老完成后 3～7 天 | 记录 dropped 事件（MVP：淡出消失；叶插 M5） |
| 季节系数 | 春秋 1.0 / 夏 0.5 / 冬 0.25 | Echeveria 春秋型（总方案 §18） |

## 6. 状态系统 → 视觉映射（R8：每个状态都要好看）

| 状态 | 触发 | 视觉参数（目标区间） |
| --- | --- | --- |
| 饱满 | water 高 | thickness ×1.0，高光柔亮，色饱和正常 |
| 轻微缺水 | water < 0.45 | thickness ×0.94，微哑光，外圈微 droop |
| 明显缺水 | water < 0.25 | thickness ×0.86，褶皱幅 0.3，droop +8°，微黄化 |
| 严重缺水 | water < 0.1 | thickness ×0.8，褶皱 0.6，整体低饱和 + 边缘红——**构成"干旱美学"而非丑** |
| 恢复 | 补水后 | 2～4 模拟日内 turgor 渐恢复，褶皱消退（过程可见，总方案 §14） |
| 徒长 | 长期光亏 | stretch 0→1：环间距 +、tilt +、叶宽 ×(1−0.3s)、色淡、farina 减 |
| 逼色 | 应激累积 | 见 §7 |
| 休眠 | 冬 | 出叶停滞、色调微灰蓝、"另一种生命状态"（总方案 §18） |

缺水褶皱实现：shader 沿 aC 的低频噪声位移 × 褶皱幅，aT 外段权重更高。

## 7. 应激变色模型（Simplified）

三累积器（02 §3.2）：`stress.light`、`stress.drought`、`stress.temp`。

```text
target = clamp( w1·lightN + w2·droughtN + w3·ΔTn , 0, 1 ) × stressColorPropensity
colorState 每模拟小时向 target 缓动：
  上升 τ ≈ 3～5 天，回落 τ ≈ 7～10 天（总方案 §16：几天后才慢慢出现）

空间分布（沿 aT 基→尖渐变，受 edgeContrast 调制）：
  colorState 0.2 → 叶尖微着色          （SignalStrength 0.3）
  colorState 0.5 → 红边成形            （0.6）
  colorState 0.8 → 边缘向内扩大        （0.75）
  colorState 1.0 → 整株偏暖            （0.9）
```

色板：stressHue 从原型应激色板取（不跨原型取色，总方案 §41.2）。

| 事件 | 预算 | 信号 |
| --- | --- | --- |
| 微风摆动 | 每真实 3～10 s 一次短动画（Ambient 态） | 纯氛围，不计入履历 |

## 10. 材质（M2 规格）

* 基底：`MeshPhysicalMaterial` + onBeforeCompile 注入（避免全自定义 shader 的维护成本）
* 饱满感：清漆层弱化 + 低高光幂 + 顶点级厚度近似 SSS（背面透光 ramp，沿 aT / aC）
* 粉霜：sheen（方向性柔光）+ 基色向白提亮去饱和 × farina + 菲涅尔边缘泛白
* turgor 影响 roughness：缺水 → 粗糙度上升、高光变碎
* 光照：1 主光（随昼夜改变角度 / 色温）+ 1 补光 + 环境半球光；软阴影仅投影到盆 / 土（桌面阴影 P1）
* 预算：整株 ≤ 3 draw call（叶 merged ×1、盆土 ×1～2）；Active 态 60 FPS @ 集成显卡（02 §7）

验收即总方案 §62：截图放大不能像塑料。
